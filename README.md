# 3B Irigem - Chat

Chat semplice per la classe 3B dell'Istituto Irigem.

### Configurazione Cloudflare Pages

Variabili d'ambiente da impostare nelle impostazioni di Cloudflare Pages:

- `DATABASE_URL`: Connection string del database Neon PostgreSQL
- `APP_SECRET`: Stringa casuale segreta per cifrare hash e token
